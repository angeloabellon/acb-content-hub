# Manifiestos importados de episodios

Esta carpeta es el único origen local que puede leer el importador de manifiestos. Solo se examinan archivos `.json` directos de esta carpeta: no hay lectura recursiva, rutas configurables ni acceso a discos externos.

`demo-regular.json` es una copia de fixture exclusivamente de demostración. No representa un episodio publicado ni una exportación de CTC Automation.

Cuando se disponga de Automation, aquí se añadirá una exportación saneada y revisada mediante *commit*; nunca una lectura directa de `CTC_WORK`.
